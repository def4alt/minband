# Presentation sources

- `deck/`: the 15-slide draft deck (data files of a claude.ai Slides artifact: `deck.json` and one
  HTML file per slide). Open placeholders: track statement, mentor scenario, team names.
- `showcase/`: the team showcase page in ASD-STE100 Simplified Technical English (what is there,
  what is left, direction, glossary). `python3 showcase/build.py` embeds `img/` into
  `showcase/build/index.html`, a single page that opens in any browser.

Images: `drone-input.jpg` is a frame of the MEVA dataset (Kitware / IARPA, CC-BY-4.0); the others
are MinBand viewer screenshots. Never add frames of the battlefield test clips here.
