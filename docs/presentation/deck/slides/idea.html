The idea

The edge runs the receiver's predictor and speaks only when the receiver would be wrong.

A ghost on the edge

Both ends run the same deterministic predictor: f32 basic ops, integer ticks, bit-identical on iPhone, WASM and aarch64.

Send the surprise

A delta goes out only when an entity leaves its threshold (θ = 15 cm). Straight lines cost nothing; turns cost a packet.

Repair by state

Updates are idempotent full states. Loss is repaired by resending current state; there is no retransmission queue.

This is DIS dead reckoning (IEEE 1278), and we say so first. What is new: the edge declares its error bar in every datagram, coasting is visible, and the heartbeat follows the link budget.

Say DIS first, before a judge does. Then: three things are ours. One byte of declared threshold per datagram, a visible coasting state, and a heartbeat that follows the budget so the floor fits a 600 bit/s link.
