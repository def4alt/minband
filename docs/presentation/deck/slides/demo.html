Pull the cable.

  1. Walk a straight line: the bytes graph stays flat. Turn: it spikes.
  2. Pull the Ethernet cable: rings grow, entities coast, then go stale.
  3. Plug it back: one keyframe and the picture snaps back.
  4. Step the link box down: hf, lora, telemetry. The heartbeat stretches.

A few hundred bytes a second, and honest when the link dies.

Fallback: recorded run, e2e/ npm run record · github.com/def4alt/minband

Pull the cable on the clean or hf profile, before stepping down: after a slow profile the twin keeps the slow heartbeat's thresholds for one coast period (about 19 s after telemetry), so coasting would show late. On telemetry, coasting starts only after ~19 s of silence and stale at 45 s; that is the 15 s heartbeat, by design. If the venue Wi-Fi or the phone fails, play the recorded fallback run.
