Bandwidth proportional to surprise.

The idea

A drone or a phone sees objects. It does not send video. It sends only the changes that the receiver cannot predict.

Both ends of the link use the same predictor. The edge keeps a copy of the receiver's picture, the ghost. The edge sends a delta only when the real object moves away from the ghost by more than the threshold. An object that walks in a straight line costs almost nothing. A turn costs one small message.

The laptop shows a live 3D twin of the scene. When the link stops, the twin does not freeze. It continues to predict, and it shows clearly how uncertain each object becomes.

1 · edgeSeeCamera, detector, tracker. iPhone now, drone later.
2 · edge coreDecideCompare each track to its ghost. Send only the surprise.
3 · linkCarryAny radio. The Pi 5 link box copies HF, LoRa, telemetry and jamming.
4 · serverRebuildTwin, fusion, repair, CoT to TAK.
5 · screenShowViewer with error rings, link activity and video comparison.

MinBand is a link layer. It is not a drone and not a detector. The delta idea is dead reckoning from DIS. Say this first. The new parts are the declared error bar in each message, the visible coasting state, and a heartbeat that follows the link budget.

Ready

Sync protocol (core, Rust)

Deltas, keyframes, acks and nacks, state repair. Protocol version 1.

Each message declares its threshold in one byte. The twin uses it to draw an honest error ring.

The keyframe cadence follows the budget: 2 s on fast links, up to 15 s at 600 bit/s. The budget counts the 28-byte UDP/IP header.

Classes include dismounts, vehicles and bicycles with their own motion limits.

core/ · 46 tests with golden vectors on x86-64, WASM and aarch64 (qemu)

Ready

Server (Node)

Receives UDP from each edge, keeps the twin, merges devices (fusion), sends acks.

Seven link profiles built in: clean, degraded, HF, LoRa, telemetry, contested, blackout. It shows airtime for each profile.

Liveness follows the cadence, so slow links do not show false "lost" states.

server/ · 86 tests · HTTP API on :8080, UDP on :7777

Ready

Viewer (browser)

Live 3D twin. Error rings grow during a blackout and snap back after it.

Link activity strip: one tick for each datagram. Video-on-this-link panel: shows how slowly video would arrive on the same link, next to an AI thumbnail.

Wide-area mode for drone-scale scenes up to hundreds of metres, with vehicle glyphs. STAGE mode for the presentation.

Partly

Battlefield detection

Moving target indication finds movers that camouflage hides. A new tracker keeps each track for longer. New classes: unclassified mover, armoured vehicle.

Test set: 8 unlabeled clips, 3 of them real military drone views. On the 5 held-out clips, the system finds about twice as many visible objects at the same precision. Track recall: 0.25 to 0.48. On the 2 military clips: 0.13 to 0.38.

These numbers come from a check by eye after the settings were frozen. They are not ground truth.

Weak points: thermal video, roof vents seen as vehicles, shadows and surf seen as movers. No military vehicle model was good enough, so the system does not use the class "armoured" yet.

Current direction

The protocol works on synthetic scenes and on real drone video. On real video, the edge tracker sets the cost, not the protocol.

New idea from the team

Video first. MinBand when the link fails.

  1. 1 · good link

    The operator sees normal video.

  2. 2 · click

    The operator clicks an object in the video to pin it. The edge keeps its track and its identity.

  3. 3 · weak link

    The screen changes from video to the twin. Pinned objects use the budget first. The operator continues to follow them.

  4. 4 · link returns

    Video returns. Pinned objects keep the same identity.

This answers the question "why not send video?". The team keeps video when the link can carry it. MinBand keeps the picture when the link cannot.

It needs: a pin message from the viewer to the edge in the ack, priority for pinned objects in the budget, an automatic change on the measured link rate, and a tracker that keeps identities for a long time. Pins are for awareness only. They do not aim anything, and affiliation stays unknown.

How to run it

Demo without a phone

  1. Build the core once. Use the commands in core/README.md.
  2. Start the server: cd server && npm install && npm run dev.
  3. Start a simulated edge: cd server && npm run sim.
  4. Start the viewer: cd viewer && npm install && npm run dev.
  5. Open http://localhost:5173. Add ?stage=1 for STAGE mode.

Replay real drone footage

  1. Follow tools/footage/README.md to make tracks.csv.
  2. Start the server and the viewer as above.
  3. Run TRACKS=<tracks.csv> TRACKS_CAMERA=<x,y,z> npm run sim in server/.

Pi 5 link box

  1. Set the WLAN country to KR on the Pi.
  2. Run sudo tools/pi-link.sh setup --password '<8+ chars>'.
  3. Connect the laptop by Ethernet. Do not connect it to the hotspot.
  4. Run sudo tools/pi-link.sh lora. Run the budget command that it shows on the laptop.

Tests and the fallback video

cd core && cargo test
cd server && npm test
cd e2e && npm install && npm test      # root is necessary for the tc tests
cd e2e && npm run record                # writes runs/fallback/*.mp4

Use binaryen 117 for wasm-opt. Older distribution versions break the WASM build.

Terms

Edge
The device with the camera. It detects and tracks objects and sends messages. In the demo, it is an iPhone.
Twin
The live 3D picture on the laptop. It shows each object at its predicted position.
Entity
One tracked object in the twin, for example one person or one car.
Detector
Software that finds objects in one image. MinBand uses YOLO models.
Tracker
Software that follows each detected object from frame to frame. It gives a position and a velocity.
Predictor
The calculation that moves an entity forward in time. It uses the last position, the velocity and a motion limit for the class. Both ends use the same calculation.
Ghost
The edge's copy of the twin's prediction for each entity. The edge compares each real track to its ghost.
Dead reckoning
Calculation of a position from a known position, a speed and the time since then. Military simulation (DIS) uses it since the 1990s.
Delta
A message with the new state of only the entities that moved past the threshold.
Threshold (θ)
The largest position error that the edge accepts before it sends a delta. The default is 0.15 m. A larger threshold sends fewer bytes.
Keyframe
A message with the state of all entities. The edge sends it at regular intervals.
Heartbeat
The regular keyframe. When the twin does not receive it, the twin knows that the link has a problem.
Budget
The maximum bit rate that the edge can use. The server tells the edge its budget in each ack.
Cadence
The keyframe interval and the related periods. They become longer when the budget becomes smaller.
Coasting
The state of an entity after the twin misses one heartbeat. The twin continues to predict it and shows it as uncertain.
Stale
The state of an entity after a longer silence. The twin shows that its position can be wrong.
Error ring (ce)
A circle around an entity. The entity is inside the circle. The ring starts at the threshold and grows while the entity coasts. CoT sends it as "ce".
Ack and nack
Messages from the server to the edge. An ack tells what arrived. A nack tells which messages are missing.
Repair
After a nack, the edge sends the current state of the affected entities. It does not send the old message again.
Fusion
The server merges entities from different devices when they are the same object.
Link profile
A set of values for rate, delay, loss and queue that copies one type of radio.
HF, LoRa, telemetry
Radio types. HF: long range, 9.6 kbit/s. LoRa: low power, about 2 kbit/s. Telemetry: the data channel of a small drone's control link, about 600 bit/s.
Airtime
The time that a radio channel is busy. On a shared radio, airtime is the real limit, not the number of bytes.
Link box
A Raspberry Pi 5 between the phone and the laptop. It acts as the radio. Its kernel adds the rate, delay and loss of a profile.
netem and tc
Linux tools that add delay, loss and rate limits to network traffic.
CoT
Cursor on Target. An XML message format for positions. TAK applications read it.
TAK
Team Awareness Kit: ATAK on Android, WinTAK on Windows, iTAK on iPhone. Map applications that show team positions.
WGS84 and MGRS
WGS84 is the latitude and longitude system of GPS. MGRS is the military grid reference, for example 52S CG 21424 59640.
Marker
A printed image on the ground. It sets the zero point and the axes of the phone's coordinates.
Golden vectors
Fixed input and expected output files. They prove that the predictor gives the same result on each computer type.
WASM and uniffi
WASM (WebAssembly) lets the Rust core run in Node.js and in a browser. uniffi connects the Rust core to Swift on the iPhone.
H.264
The usual video compression standard. MinBand compares its bytes to H.264 video of the same scene.
CRF
The quality setting of an H.264 encoder. A lower number gives better quality and more bits. CRF 23 is the default quality.
Baselines A, B, C
A: H.264 video. B: naive metadata, with all entities 30 times each second. C: one 150-byte AI thumbnail image every few seconds.
Ego-motion
The motion of the camera itself. The footage tool removes it with a homography: a 3 × 3 matrix that maps one view of flat ground to another view.
MTI
Moving target indication. Detection of objects from their motion, not from their appearance. It finds movers that camouflage hides.
Pin
An operator selection of one object. The system keeps the identity of a pinned object and sends it first when the budget is small. A pin is for awareness only.
Dismount
A person on foot. MinBand shows the class "person" as "dismount".
Affiliation unknown
MinBand does not identify friend or enemy. A human operator makes that decision.
Held-out clip
A test video kept separate from development. The detector runs on it only once, after its settings are frozen.
End-to-end test
A test that runs the real server, simulated edges and the viewer together.
STAGE mode
A presentation view of the viewer with extra panels: link activity and video on this link.
Fallback run
A recorded video of the demo. Use it when the live demo fails.
bit/s, kbit/s, B/s
Bits each second, thousands of bits each second, bytes each second. One byte is 8 bits.

No term matches. Try a shorter word.
